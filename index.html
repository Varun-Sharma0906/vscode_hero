Code with confidence

IntelliSense

Go beyond syntax highlighting and autocomplete with IntelliSense, which provides smart completions based on variable types, function definitions, and imported modules.

Multi-agent Sessions

Run multiple AI agents side-by-side. Refactor code, wire up services, and debug — all happening concurrently within your editor.

Built-in Git

Reviewing diffs, staging files, and making commits directly from the editor. Any Git and SCM provider is available from the integrated source control panel.

Extensions

Install extensions to add new languages, themes, debuggers, and to connect to additional services. Extensions run in separate processes so they won't slow your editor down.

Debugging

Debug code right from the editor. Launch or attach to your running apps with breakpoints, call stacks, and an interactive console built in.

Remote Development

Work with code on remote machines, containers, or WSL as seamlessly as if it were local. Use SSH, Dev Containers, and GitHub Codespaces directly from VS Code.
